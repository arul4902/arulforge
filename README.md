# ARULFORGE — Creative Web Studio

> **"Ideas enter. Digital experiences are forged."**  
> **"WE FORGE DIGITAL EXPERIENCES THAT MAKE BRANDS IMPOSSIBLE TO IGNORE."**

ArulForge is a solo creative web studio founded by Arul S. that builds premium, conversion-focused websites and digital experiences for businesses, brands, creators, and service professionals.

---

## ⚡ Tech Stack & Architecture

- **Framework**: React 19 + TypeScript (Vite 8)
- **Styling**: Tailwind CSS + Custom CSS Variables & Clamps
- **Motion & Physics**: Framer Motion + Lenis Smooth Inertia Scroll
- **Icons**: Lucide React + Bespoke Scalable Brand SVG Vectors
- **Aesthetic**: Dark, Technical, Industrial, Editorial, Cinematic, Minimal, Sharp, Premium

---

## 🌌 Signature Visuals & Interactions

1. **Forge Intro (01)**: 1.5–2s high-impact brand assembly sequence (`[ IDEA ]` → laser trace → `[ ARULFORGE ]` fragmented character assembly → shutter split reveal). Shortened/skipped automatically on repeat session visits.
2. **The Forge Cursor**: Contextual desktop spring-physics cursor with states:
   - Default: cyan dot + subtle outer ring
   - Hover project: expands with `"VIEW"`
   - Hover CTA: expands with `"FORGE →"`
   - Hover draggable technology belt: `"DRAG"`
   - Hover capability row: `"EXPLORE"`
   - Automatically disabled on touch/mobile devices (`pointer: coarse`).
3. **The Forge Grid**: Subtle background technical coordinate grid with cursor-reactive crosshair node illumination.
4. **The Forge Core (Hero)**: Interactive procedural 3D object dynamically illustrating the core brand metaphor: `CHAOS → STRUCTURE → WEBSITE`.
5. **Instagram → Website Transformation**: Interactive 5-stage transformation demonstrating the shift from social media limits to an owned, high-conversion web platform:
   - Profile Avatar → Brand Identity
   - Bio Text → Conversion Hero
   - Story Highlights → Structured Services
   - Grid Posts → Case Studies
   - DM Button → 3-Step Project Builder
6. **Selected Forges (05)**: 6 real production builds with natural screenshot ratios, live links, and technical architecture specifications:
   - `01` **AI Mock Interview Coach** (AI Web Application)
   - `02` **HVAC Services** (Business Website)
   - `03` **Plumbing Services** (Business Website)
   - `04` **Summit Roofing Solutions** (Business Website)
   - `05` **The Black Trendz** (Web Experience)
   - `06` **Basil Town** (Web Project)
7. **What We Forge (06)**: 5 interactive full-width capability rows with text shift, rotating index, preview silhouettes, and growing cyan laser line.
8. **The Forge Stack (07)**: Infinite draggable horizontal technology belt with inertia, category filters, and metadata. No fake percentage bars.
9. **From Idea to Live (08)**: 4-stage production pipeline connected by a continuous cyan Forge Line (particles → connected channels → structured grid → live browser outline with `● LIVE`).
10. **Why ArulForge (09)**: "NOT JUST ANOTHER WEBSITE" with 4 foundational principles.
11. **Behind the Forge (10)**: Subtle founder credit for Arul S. with GitHub & LinkedIn verification.
12. **Project Enquiry Modal (11)**: Fullscreen 3-step interactive project scoping flow with WhatsApp dispatch, clipboard brief copy, and Instagram alternative.
13. **Oversized Studio Footer (12)**: Edge-to-edge `ARULFORGE` wordmark, mission statement, channel links, and pulsing operational status.
14. **Mobile Sticky CTA**: Subtle bottom-right floating pill appearing after hero without obstructing content.
